# Social Media Engagement Analytics Dashboard

An interactive Power BI dashboard for analyzing social media engagement across platforms and content types.

## Project Overview

This project analyzes social media performance using engagement, reach, and content-level metrics. The dashboard provides an interactive view of how different platforms and content types contribute to overall engagement.

The project focuses on transforming raw data into an interactive analytical dashboard using Power BI and Power Query.

## Dashboard Features

### Engagement Overview
- Total Likes
- Total Comments
- Total Shares
- Overall Engagement
- Platform-wise engagement comparison
- Content-type engagement distribution
- Monthly engagement trends
- Interactive platform filtering

### Performance Analysis
- Platform contribution to overall engagement
- Engagement by content type
- Reach vs Engagement correlation
- Platform and content-type comparison
- Reach growth over time
- Overall engagement performance
- Platform × content-type engagement table

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis
- Data Modeling

## Dashboard Pages

### Page 1 — Engagement Overview

Provides a high-level view of social media performance through KPI cards, platform comparisons, content-type analysis, and monthly engagement trends.

### Page 2 — Engagement Analysis

Provides deeper analysis of platform contribution, content-type performance, reach vs engagement relationships, and platform/content-type comparisons.

### Page 3 — Performance Trends

Focuses on reach growth, overall engagement performance, and detailed platform × content-type engagement.
